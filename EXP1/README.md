# EXP 1: ER Diagram for an Indian E-Commerce Platform

## Question

Design an ER diagram for an Indian e-commerce platform with entities Customer, Product, Order, OrderItem, Seller, Category, Payment, Delivery, Address. Specify primary keys, composite and multi-valued attributes, weak entities, specialization of Product, and participation constraints.

## Diagram Files

The same diagram has been added in the following formats:

- PNG: `er.png`
- XML (draw.io): `er.drawio`
- SVG: `ER.drawio.svg`

## Notes

This repository contains the ER diagram for the Indian e-commerce platform, including:

- Primary keys for each entity
- Composite and multi-valued attributes
- Weak entities and their identifying relationships
- Product specialization (for example, Electronics, Fashion, Grocery, etc.)
- Participation constraints between related entities
- Customer, Order, Payment, Delivery, and Address modeling for a realistic e-commerce system
